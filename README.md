# R-EXIF 🔍

R-EXIF is a lightweight, browser-based EXIF metadata viewer developed by Rivek Raj Tamang (Rivudon).

The tool allows users to upload or drag-and-drop image files and instantly inspect embedded EXIF metadata without uploading images to any external server.

## Features

- 📸 Extract EXIF metadata from images
- 🗺️ GPS coordinate extraction with interactive map view
- 📍 Location visualization using Leaflet and OpenStreetMap
- 🖼️ Image preview panel
- 🔎 Complete EXIF metadata table
- 🔒 Hide camera serial numbers with a single click
- ⚠️ Basic detection and highlighting of suspicious metadata payloads
- 🎨 Clean cyber-themed dark UI
- 📂 Drag & Drop image support
- 🌐 Fully client-side processing (images never leave your browser)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Exifr.js
- Leaflet.js
- OpenStreetMap

## Usage

1. Open `index.html`
2. Click **Select Image** or drag & drop an image file
3. View:
   - Camera Make & Model
   - GPS Location
   - Image Preview
   - Full EXIF Metadata
4. Toggle **Hide Serial Numbers** if required

## Privacy

R-EXIF processes images entirely within the browser.

No images, metadata, or GPS information are uploaded, stored, or transmitted to any external server.
